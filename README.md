# அடவி – தமிழ்நாடு வனங்கள் & புலிகள் காப்பக வழிகாட்டி

இந்த Android Studio project, கொடுக்கப்பட்ட Google AI Studio app-ஐ Android WebView app ஆக திறக்கிறது.

## Build
1. Android Studio-ல் இந்த `AdaviAndroid` folder-ஐ Open செய்யவும்.
2. Gradle Sync முடியும் வரை காத்திருக்கவும்.
3. Build > Generate Signed Bundle / APK > Android App Bundle தேர்வு செய்யவும்.
4. Play Console-ல் `.aab` upload செய்யவும்.

## App ID
`com.adavi.guide`

## Version
1.0.0 (versionCode 1)

## முக்கிய குறிப்பு
App-ன் online content, Google AI Studio URL-ல் கிடைப்பதைப் பொறுத்தது. Offline native app வேண்டுமெனில் source code-ஐ Android-க்கு முழுமையாக port செய்ய வேண்டும்.
